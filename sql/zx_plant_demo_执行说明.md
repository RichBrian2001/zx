# 植物个性化推荐系统 Demo SQL 执行说明

## 文件清单

- zx_plant_demo_00_execute.sql：阶段 1 总执行入口。
- zx_plant_demo_01_schema.sql：业务表结构最终执行版。
- zx_plant_demo_02_menu.sql：管理端菜单、按钮权限和业务角色最终执行版。
- zx_plant_demo_03_seed.sql：真实样例数据最终执行版。

## 执行顺序

- 命令行模式：进入 sql 目录后，使用 `mysql --default-character-set=utf8mb4 -uroot -p proj_zx` 连接目标数据库，再执行 `source zx_plant_demo_00_execute.sql;`。
- 图形化工具模式：先确认脚本文件编码为 UTF-8 / utf8mb4，再按 01 -> 02 -> 03 顺序依次执行。
- 若系统库尚未初始化，必须先执行若依原始脚本 ry_20260417.sql，再执行本套脚本。

## 重跑口径

- 首次初始化或整库重装：执行 zx_plant_demo_00_execute.sql。
- 仅业务表结构调整：执行 zx_plant_demo_01_schema.sql，再执行 zx_plant_demo_03_seed.sql。
- 仅管理端菜单和权限调整：执行 zx_plant_demo_02_menu.sql。
- 仅刷新演示数据：执行 zx_plant_demo_03_seed.sql。
- 禁止手工删部分业务表数据后混跑脚本，统一按上述口径执行。

## 数据说明

- 植物主数据固定为 47 条真实可演示植物。
- 标签字典为 27 条，问卷、画像、推荐记录各 8 组，推荐明细 24 条，内容文章 8 篇。
- 同步包含分类、标签、详情、规则、问卷、画像、推荐记录、推荐明细、反馈、收藏、内容、导入任务样例。
- 菜单号段固定为 2000 到 2193。
- 业务角色固定为 3000，对应 role_key 为 plant_admin。

## 注意事项

- 该套 SQL 已完成脚本级检查，并已在本地 proj_zx MySQL 实库按总入口脚本完成重导和样例规模核对。
- 当前已确认植物 47 条、植物详情 47 条、标签 27 条、标签关系 403 条、规则 18 条、问卷 8 组、画像 8 组、推荐记录 8 组、推荐明细 24 条、文章 8 篇。
