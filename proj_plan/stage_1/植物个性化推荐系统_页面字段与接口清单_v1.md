# 植物个性化推荐系统 Demo 页面字段与接口清单 v1

## 1. 文档定位

- 本文档用于冻结管理端和用户端页面字段、HTTP 接口和后端骨架落点。
- 本文档是阶段 2 页面实现和阶段 3 后端骨架实现的直接基线。
- 本文档中所有页面字段必须对应真实表字段、真实关联字段或明确聚合计算字段。

## 2. 统一口径

### 2.1 字段来源口径

- 真实字段：直接取自业务表字段，如 zx_plant.plant_name。
- 关联字段：通过主表和关联表拼出，如 categoryName 来自 zx_plant.category_id 关联 zx_plant_category.category_name。
- 计算字段：必须写明计算方式，如 plantTotal = count(zx_plant where del_flag = '0')。
- 枚举翻译字段：本质来源仍是数据库编码字段，只是在前端或返回 VO 中翻译为中文标签。
- 静态文案不纳入字段清单：首页介绍文案、按钮文案、空状态文案由前端静态实现，不作为后端返回字段。

### 2.2 返回结构口径

- 管理端列表接口统一返回 RuoYi TableDataInfo，字段口径为 rows + total。
- 管理端详情、新增、编辑、状态切换接口统一返回 AjaxResult。
- 用户端接口统一返回 AjaxResult，data 节点承载业务对象。
- 用户端植物业务链路内部仍使用 visitorUid，前端首次获取后写入本地缓存，后续问卷、推荐、历史、收藏、反馈链路复用；对外身份展示统一复用现有登录态，通过 /getInfo 获取当前用户 userId、userName、nickName，通过 /logout 执行退出登录。

### 2.3 业务枚举口径

- difficultyLevel：1 低养护，2 中等养护，3 进阶养护。
- priceLevel：1 低预算，2 中预算，3 高预算。
- displayStatus：0 上架，1 下架。
- commonStatus：0 正常或启用，1 停用。
- articleStatus：0 发布，1 草稿。
- feedbackType：1 喜欢，2 不喜欢。
- favoriteStatus：0 收藏中，1 已取消。
- importTaskStatus：0 待处理，1 处理中，2 已完成，3 失败。

## 3. 管理端页面字段清单

### 3.1 A01 系统工作台

- 页面路由：/plant-admin/dashboard。
- 查询字段：startDate、endDate。该组字段为请求过滤参数，统计窗口统一作用于 zx_recommend_record.recommend_time、zx_feedback_record.create_time、zx_questionnaire_record.submit_time。
- 统计卡片字段：plantTotal、onlinePlantTotal、categoryTotal、recommendTotal、todayRecommendTotal、feedbackTotal、likeFeedbackTotal、dislikeFeedbackTotal。
- 字段来源：
  plantTotal = count(zx_plant where del_flag = '0')；onlinePlantTotal = count(zx_plant where del_flag = '0' and display_status = '0')；categoryTotal = count(zx_plant_category where del_flag = '0')；recommendTotal = count(zx_recommend_record)；todayRecommendTotal = count(zx_recommend_record where date(recommend_time) = 当前统计日)；feedbackTotal = count(zx_feedback_record)；likeFeedbackTotal = count(zx_feedback_record where feedback_type = '1')；dislikeFeedbackTotal = count(zx_feedback_record where feedback_type = '2')。
- 榜单字段：plantId、plantName、coverImage、recommendCount、likeCount、favoriteCount。
- 榜单来源：zx_recommend_item.plant_id 聚合推荐次数，zx_feedback_record.plant_id 聚合喜欢次数，zx_favorite_record.plant_id 聚合收藏次数，植物基础信息来自 zx_plant。
- 最近记录字段：recordId、visitorUid、topPlantId、topPlantName、recommendTime、resultCount。
- 最近记录来源：zx_recommend_record 关联 zx_plant。

## 4. 用户端页面字段清单

### 4.0 用户端公共头部

- 适用页面：U01-U09。
- 展示字段：loginStatus、currentUserId、currentUserName、currentNickName。
- 字段来源：loginStatus 由前端 token 状态判断；currentUserId、currentUserName、currentNickName 来自 /getInfo 返回的 user.userId、user.userName、user.nickName。
- 交互字段：logoutAction。点击右上角身份区后触发退出登录动作，调用 /logout。

### 4.1 U01 首页模块

- 页面路由：/plant-demo/home。
- 后端动态字段：featuredPlantList、latestArticleList、plantTotal、recommendTotal。
- featuredPlantList 字段：plantId、plantName、coverImage、plantSummary、difficultyLevel、priceLevel、suitableScene。
- latestArticleList 字段：articleId、title、coverImage、summary、publishTime、relatedPlantId。
- 聚合字段来源：plantTotal = count(zx_plant where del_flag = '0' and display_status = '0')；recommendTotal = count(zx_recommend_record)。
- 数据来源：featuredPlantList 来自 zx_plant；latestArticleList 来自 zx_content_article where status = '0'；系统介绍文案和场景入口卡片为前端静态实现。

### 4.2 U02 问卷模块

- 页面路由：/plant-demo/questionnaire。
- 表单字段：scene、light、space、pet、budget、care、style、goal、sourceTerminal、sourceChannel。
- 入库字段：visitorUid、answerJson、environmentSummary、preferenceSummary、budgetValue、submitIp、submitTime。
- 字段来源：用户填写表单后，scene、light、space、pet、budget、care、style、goal 写入 zx_questionnaire_record.answer_json；environmentSummary、preferenceSummary 为后端根据表单内容生成；budgetValue 单独写入 zx_questionnaire_record.budget_value。

### 4.3 U03 推荐结果模块

- 页面路由：/plant-demo/result/:recordId。
- 页面头字段：recordId、visitorUid、recommendTime、totalCandidateCount、resultCount、topPlantId、topPlantName。
- 结果卡片字段：plantId、plantName、coverImage、plantSummary、difficultyLevel、priceLevel、petSafeFlag、purgeEffectFlag、aromaFlag、suitableScene、rankNum、scoreTotal、reasonText、riskTips。
- 解释区字段：matchRuleJson、scoreDetailJson。
- 数据来源：zx_recommend_record 关联 zx_recommend_item、zx_plant、zx_plant_detail；topPlantName 来自 zx_plant。

### 4.4 U04 植物详情模块

- 页面路由：/plant-demo/plant/:plantId。
- 基础字段：plantId、plantName、aliasName、coverImage、plantSummary、difficultyLevel、priceLevel、petSafeFlag、purgeEffectFlag、aromaFlag、suitableScene。
- 养护字段：lightRequirement、waterRequirement、temperatureRange、humidityRequirement、growCycle、careTips、riskTips、displayContent。
- 标签字段：tagList[{tagId, tagName, tagCode, tagGroup, scoreWeight}]。
- 内容字段：articleList[{articleId, title, summary, publishTime}]。
- 数据来源：zx_plant、zx_plant_detail、zx_plant_tag_rel、zx_plant_tag、zx_content_article。

### 4.5 U05 历史记录模块

- 页面路由：/plant-demo/history。
- 查询字段：visitorUid。该字段为前端内部链路字段，从本地缓存读取后传入接口，不作为页面对外身份展示字段。
- 列表字段：recordId、recommendTime、topPlantId、topPlantName、topPlantCoverImage、environmentSummary、preferenceSummary、resultCount。
- 数据来源：zx_recommend_record 关联 zx_plant 和 zx_questionnaire_record；topPlantCoverImage 来自 zx_plant.cover_image。

### 4.6 U06 收藏模块

- 页面路由：/plant-demo/favorite。
- 查询字段：visitorUid。该字段为前端内部链路字段，不作为页面对外身份展示字段。
- 列表字段：favoriteId、plantId、plantName、coverImage、plantSummary、difficultyLevel、priceLevel、status、createTime。
- 数据来源：zx_favorite_record 关联 zx_plant；仅返回 status = '0' 的收藏记录。

### 4.7 U07 反馈模块

- 页面路由：/plant-demo/feedback/:recordId。
- 页面初始化字段：recordId、visitorUid、recommendTime、resultItems[{plantId, plantName}]。
- 表单字段：recordId、visitorUid、plantId、feedbackType、feedbackReason、extraNote。
- 入库字段：feedbackId、visitorUid、recordId、plantId、feedbackType、feedbackReason、extraNote、createTime。visitorUid 仅用于内部业务链路关联，不作为对外身份展示字段。
- 数据来源：初始化数据来自 zx_recommend_record、zx_recommend_item、zx_plant；提交后写入 zx_feedback_record。

## 8. 冻结约束

- 页面开发只允许使用本文档已冻结字段，新增字段必须先补业务表或明确聚合公式。
- 管理端新增接口必须归属到 /plant/admin/*，用户端新增接口必须归属到 /plant/app/*。
- 用户端不得引入后台菜单体系，全部走固定路由。
- 问卷字段不得拆成无来源的新表字段，首版统一沉淀到 zx_questionnaire_record.answer_json。
- 历史、收藏、反馈三条植物业务链路内部仍以 visitorUid 贯通，不新增独立前台注册体系；用户端公共头部身份展示统一复用现有 RuoYi 登录态。
